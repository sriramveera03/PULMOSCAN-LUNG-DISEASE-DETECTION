# PULMOSCAN-LUNG-DISEASE-DETECTION
Pulmoscan is a web-based application developed to assist in the early detection of major lung diseases using chest X-ray images. The sustem uses deep learning techniques to analyze medical images and predict the presence of diseases such as Tuberculosis, Pneumonia,and lung cancer(lung nodules).

The application provides an easy-to-use interface where users can upload chest X-ray images, and the trained deep learning model processes the image to provide disease prediction results. This helps support faster and more efficient diagnosis.
The project was developed as a final year academic project by a team of four members and integrates machine learning with web technologies to build a functional medical diagnostic support system.

Technologies Used:
Python
Deep Learning (CNN)
Flask Framework
HTML
CSS

Key Features:
Upload chest X-ray images for analysis
Automated detection of multiple lung diseases
Web-based interface for easy accessibility
Deep learning model for medical image classification
This project demonstrates the practical application of machine learning and web development in the healthcare domain to support early disease detection.
